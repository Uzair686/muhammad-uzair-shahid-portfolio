## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Uzair686/muhammad-uzair-shahid-portfolio.git
```

### 2. Navigate into the project

```bash
cd muhammad-uzair-shahid-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:3000
```

### 5. Create a production build

```bash
npm run build
```

### 6. Preview the production build

```bash
npm run preview
```
